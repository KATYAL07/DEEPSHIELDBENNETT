# Deep Shield media analysis landing page

React + Vite implementation of the Deep Shield explainable media-analysis landing page.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

The page is implemented in [src/components/ui/cairn-agents-landing.tsx](./src/components/ui/cairn-agents-landing.tsx) and includes the interactive demo, simulated support call, responsive layouts, reduced-motion handling, and talk-to-us form.
